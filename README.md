# 閱讀冒險島——四年級深層閱讀闖關網站

專為台灣國小四年級學生與國小教師打造的 **PIRLS 四層次深層閱讀互動教學平台**。
結合 PDF 內嵌文章閱讀、四層次思維闖關（提取訊息、直接推論、詮釋統整、評價省思）、即時回饋解析、作答狀態持久化與學習成果證書。

---

## 核心功能特色

1. **左右分欄雙模閱讀（桌機優先）**：
   - 左側內嵌 PDF 閱讀器，支援 **放大 (Zoom In)**、**縮小 (Zoom Out)**、**全螢幕閱讀** 與 **另開原檔備援**。
   - 右側題目作答區，學生可以一邊對照文章一邊回答問題。
   - 平板與手機自動轉化為「查看文章 / 進行答題」快速切換頁籤，防止內容被裁切。
2. **PIRLS 四層次 13 題完整題庫**：
   - 第一關：提取訊息（2 題）
   - 第二關：直接推論（4 題）
   - 第三關：詮釋與統整（4 題，含配對題、情節排序題、生活遷移簡答題）
   - 第四關：評價與省思（3 題，含修辭評析與多維度觀點論述簡答題）
3. **真實教育回饋，不假裝 AI 精準評分**：
   - 簡答題（第 10 題、第 13 題）提供國小四年級「學生自我檢核規準表」與「優秀範例作答」，讓學生誠實檢核自己的答題要素。
4. **進度防呆與持久化保存**：
   - 作答進度即時自動保存至瀏覽器 `localStorage`，刷新網頁進度與答案絕不遺失。
5. **兒童友善 3D Q 版視覺**：
   - 柔和馬卡龍配色（晨曦藍、薄荷綠、向日黃、珊瑚粉、淡紫）。
   - Web Audio API 免下載無依賴輕量音效（答對琶音、重試低音），可一鍵關閉。
   - 支援無障礙「減少動態效果」開關。
6. **學習成果報告與證書列印**：
   - 通關後生成總得分、四層次雷達能力長條圖、題目總回顧，支援一鍵列印紙本成果學習單。

## 教師更換文章教學（免改介面程式碼）

教師若要更換閱讀文章，只需進行以下 3 個步驟：

### 第一步：放入新文章 PDF
將您的文章 PDF 檔案直接複製到本專案資料夾中（與 `index.html` 同一目錄），例如：
`my-new-story.pdf`

### 第二步：修改 `articles-config.js`
開啟 `articles-config.js`，修改文章資訊與路徑：
```javascript
const ARTICLES_CONFIG = [
  {
    id: "my-new-story",
    title: "新文章標題",
    author: "作者姓名",
    source: "文章來源或專欄名稱",
    difficulty: "★★★",
    pdfUrl: "my-new-story.pdf", // 直接填寫同目錄下的 PDF 檔名
    summary: "新文章的簡短介紹..."
  }
];
```

### 第三步：更新 `quiz-data.js` 題目
開啟 `quiz-data.js`，依照四層次結構修改題目文字、選項、正確答案與文章依據。修改完成存檔後，重新整理網頁即可即時呈現新測驗！

## 部署至 GitHub Pages 教學

本專案採用純前端靜態架構，所有資源引用均使用相對路徑，完全相容 GitHub Pages：

1. **建立 GitHub Repository**：在 GitHub 上建立一個新的公開儲存庫（例如 `deep-reading-adventure`）。
2. **上傳專案檔案**：將本資料夾內的所有檔案（包含 `index.html`、`css/`、`js/`、`public/`）推送至 GitHub 的 `main` 分支。
3. **啟用 GitHub Pages**：
   - 進入儲存庫的 **Settings（設定）** ➔ **Pages**。
   - 在 **Build and deployment** 下方的 **Source** 選擇 **Deploy from a branch**。
   - 分支選擇 **`main`**，資料夾選擇 **`/ (root)`**，點擊 **Save**。
4. **完成上線**：等待約 1~2 分鐘，即可透過網址 `https://[你的帳號].github.io/deep-reading-adventure/` 開啟使用！
